What I Built

Learning Portfolio ประกอบด้วยส่วนแนะนำตัวเอง งานที่สร้าง ขั้นตอนการทำงาน และบทเรียนที่ได้รับ

การเกิด Client / Server: ในขณะที่เปิดเว็บไซต์นี้จากเครื่องของตนเองโดยตรงผ่านไฟล์ จะเกิดขึ้นเฉพาะ Client ที่ทำการอ่านและแสดงผลไฟล์ HTML/CSS เท่านั้น ยังไม่มี Server เกิดขึ้นจริง เพราะยังไม่ได้มีการร้องขอข้อมูลผ่านโปรโตคอล HTTP/HTTPS ไปยัง Web Server

How I Built It

ผมพัฒนางานนี้โดยเริ่มจากการออกแบบโครงสร้างข้อมูลด้วย HTML ใช้ Semantic Tags เช่น header main section และ footer และเขียน css/style.css เพื่อจัดแต่งสีสันและรูปแบบการวางหน้าเว็บ

เครื่องมือและแหล่งเรียนรู้: ใช้ VS Code ในการเขียนโค้ด และศึกษาจากเอกสารการเรียนวิชา CS100

Reflection

  1. ปัญหาหรือความท้าทายที่พบและการแก้ไข: การจัดและออกแบบไม่เป็นอย่างที่คิดทำให้ต้องทดลองหลายรอบ
  2. ความเข้าใจเกี่ยวกับการพัฒนาเว็บที่มากขึ้น: เข้าใจการทำงานระหว่าง html และ css รวมถึงความสำคัญในการเขียนโค้ดเป็นระเบียบ
  3. สิ่งที่อยากปรับปรุงหรือเพิ่มหากพัฒนาต่อ: อยากให้หน้าเว็บมีลูกเล่นและความสวยงามมากขึ้น
